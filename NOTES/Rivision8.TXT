Routing in React :
    Routing in React is the process of displaying different components or views based 
    on the URL path. React applications commonly use React Router for client-side routing, 
    which allows users to navigate between different routes without performing a full page reload.

Imagine an e-commerce application:

    /              → Home
    /products      → Products
    /cart          → Cart
    /login         → Login
    /profile       → Profile

    Routing connects these URLs to the corresponding React components.

    For example:

    URL
    ↓
    /products
    ↓
    React Router
    ↓
    Products component
    ↓
    Products page displayed
3. Why do we need routing? :

    Without routing, a React application would have difficulty handling different URLs/views.

    For example:

    myapp.com/
    myapp.com/products
    myapp.com/cart
    myapp.com/profile

    Routing allows each path to display the appropriate UI

React Router example

    First install React Router:

    npm install react-router-dom

    Then:

    import { BrowserRouter, Routes, Route } from "react-router-dom";

    function App() {
    return (
        <BrowserRouter>
        <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/products" element={<Products />} />
            <Route path="/cart" element={<Cart />} />
        </Routes>
        </BrowserRouter>
    );
    }

    Now:

    /          → Home
    /products  → Products
    /cart      → Cart

Important routing components
    BrowserRouter

    Provides the routing context and integrates routing with the browser's URL/history.

    <BrowserRouter>
    ...
    </BrowserRouter>

    Think:

    BrowserRouter = enables routing for the application.

    Routes

    Contains the route definitions.

    <Routes>
    ...
    </Routes>

    Think:

    Routes = collection of routes.

    Route

    Connects a URL path to a React element.

    <Route path="/products" element={<Products />} />

    Think:

    Route = which component should appear for this path?

Navigation

    For navigation inside a React application, we commonly use Link.

    import { Link } from "react-router-dom";

    <Link to="/products">Products</Link>

    Clicking it navigates to:

    /products

    without the normal full-page reload associated with a traditional <a href> navigation.

Dynamic Routing :

    Sometimes the URL contains a value.

    For example:

    /products/101
    /products/102
    /products/103

    We can define:

    <Route path="/products/:id" element={<Product />} />

    Then /products/101 matches the route with:

    id = 101

    Inside the component:

    import { useParams } from "react-router-dom";

    function Product() {
    const { id } = useParams();

    return <h1>Product ID: {id}</h1>;
    }


Routing vs React Router :

    These are not exactly the same thing.

Routing:

    The concept/process of mapping URLs to views.

React Router:

    A library used to implement routing in React applications.

    So:

    Routing = concept
    React Router = tool/library used to implement it

Routing and SPA :
    For example:

    Home
    ↓
    Products
    ↓
    Product Details
    ↓
    Cart

    The UI can change as the URL changes without requiring a full page reload for every navigation.

Important terms :
    BrowserRouter →     provides routing context
    Routes →            contains routes
    Route →             maps path to component/element
    Link →              navigation
    useNavigate →       programmatic navigation
    useParams →         access dynamic route parameters
    Outlet →            renders nested child routes


Nested Routing :
    Nested routing is a routing pattern where a route is defined inside another route. 
    The parent route provides a common layout, while the child route renders its specific 
    content inside the parent's <Outlet>. It is useful for applications with hierarchical 
    pages such as dashboards, profiles, and settings.

Simple understanding

    Imagine this structure:

    Dashboard
    ├── Home
    ├── Profile
    └── Settings

    You want the URL to be:

    /dashboard/home
    /dashboard/profile
    /dashboard/settings

    The Dashboard part is common, while the content changes.

    We can create nested routes:

    import { BrowserRouter, Routes, Route } from "react-router-dom";

    function App() {
    return (
        <BrowserRouter>
        <Routes>
            <Route path="/dashboard" element={<Dashboard />}>
            <Route path="home" element={<Home />} />
            <Route path="profile" element={<Profile />} />
            <Route path="settings" element={<Settings />} />
            </Route>
        </Routes>
        </BrowserRouter>
    );
    }

    Parent component:

    import { Outlet } from "react-router-dom";

    function Dashboard() {
    return (
        <div>
        <h1>Dashboard</h1>

        <Outlet />
        </div>
    );
    }

    Now:

    /dashboard/home
            ↓
    Dashboard
            +
        Home

    And:

    /dashboard/profile
            ↓
    Dashboard
            +
        Profile
    The important connection
    Nested Route
        ↓
    Outlet
        ↓
    Child component appears here

    So remember:

    Nested Routing + Outlet = Parent layout + changing child content

Dynamic Routing :
    Dynamic routing is a routing pattern where part of the URL is treated as a dynamic parameter 
    rather than being fixed. React Router allows this using route parameters such as :id. 
    The parameter can then be accessed using useParams().

    Suppose you have 1,000 products.

    You don't want to create:

    /products/1
    /products/2
    /products/3
    ...
    /products/1000

    Instead, create one dynamic route:

    <Route path="/products/:id" element={<Product />} />

    Here:

    :id

    is the dynamic parameter.

    Now all of these can match:

    /products/101
    /products/205
    /products/999
    Getting the dynamic value
    import { useParams } from "react-router-dom";

    function Product() {
    const { id } = useParams();

    return <h1>Product ID: {id}</h1>;
    }

    If the URL is:

    /products/101

    then:

    id = "101"

    If the URL is:

    /products/500

    then:

    id = "500"

    The same component handles all product IDs.


Route Parameters : 
    Route parameters are dynamic values included as part of a URL path. In React Router, 
    they are defined using a colon, such as :id, and can be accessed inside the component 
    using the useParams() hook.

    Suppose you have:

    /products/101
    /products/102
    /products/103

    Instead of creating three routes, we create one:

    <Route path="/products/:id" element={<Product />} />

    Here :id is the route parameter.

    Inside Product:

    import { useParams } from "react-router-dom";

    function Product() {
    const { id } = useParams();

    return <h1>Product ID: {id}</h1>;
    }

    If URL is:

    /products/101

    then:

    id === "101"
    Multiple route parameters
    <Route
    path="/users/:userId/orders/:orderId"
    element={<Order />}
    />

    URL:

    /users/25/orders/5001

    Then:

    const { userId, orderId } = useParams();
    userId → "25"
    orderId → "5001"
    Short note

    Route Parameter = dynamic value inside the URL path.


Query Parameters :
    Query parameters are key-value pairs added to the URL after a ?. They are commonly used to 
    represent optional information such as search terms, filters, sorting, or pagination. 
    In React Router, they can be accessed using the useSearchParams() hook.
    Suppose you want to search products:

    /products?search=iphone

    Here:

    search = iphone

    is a query parameter.

    Another example:

    /products?category=mobile&sort=price

    There are two query parameters:

    category → mobile
    sort     → price

    Notice the difference:

    /products/101
            ↑
        Route parameter


    /products?search=iphone
            ↑
        Query parameter
    Using useSearchParams()
    import { useSearchParams } from "react-router-dom";

    function Products() {
    const [searchParams] = useSearchParams();

    const search = searchParams.get("search");

    return <h1>Search: {search}</h1>;
    }

    For:

    /products?search=iphone

    we get:

    search = "iphone"


Protected Routes :
    A protected route is a route that can only be accessed when a particular condition is 
    satisfied, usually when the user is authenticated. If the condition is not satisfied, 
    the application redirects the user to another route, such as a login page.
    Simple understanding

    Imagine your application has:

    /login
    /products
    /profile
    /admin

    Anyone can access:

    /products

    But only logged-in users should access:

    /profile
    /admin

    So we protect those routes.

    Think:

    User tries /profile
            ↓
    Is user logged in?
      ↙   ↘
    Yes     No
     ↓       ↓
    Profile    Login
