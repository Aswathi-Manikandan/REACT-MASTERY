HOOKS :

    Hooks are special functions provided by React that allow functional components to use React
    features such as state, effects, context, refs, and more.

    Before Hooks, state and lifecycle-related features were mainly associated with class components. 
    Hooks made it possible to use these features in functional components.

    Examples:

    useState      → state
    useEffect     → side effects
    useContext    → context
    useRef        → refs
    useReducer    → complex state
    useMemo       → memoization
    useCallback   → memoized functions

Why were Hooks introduced? :

    Hooks were introduced to make it easier to:

    Use state in functional components
    Handle side effects
    Reuse stateful logic
    Work with context
    Access DOM elements
    Organize component logic more clearly


What is useState() : 
    useState is a React Hook that allows a functional component to create and manage state. 
    It returns the current state value and a setter function used to update that state. 
    When the state is updated using the setter function, React schedules a re-render so 
    the UI can reflect the new state.

What does useState() return? :
    It returns an array containing two values:
    [currentState, stateUpdater]

Types of State

    useState can store almost any JavaScript value.

Number  :
    const [age, setAge] = useState(22);
String  :
    const [name, setName] = useState("Aswathi");
Boolean :
    const [isLoggedIn, setIsLoggedIn] = useState(false);
Array   :
    const [skills, setSkills] = useState(["JavaScript", "React"]);
Object  :
    const [user, setUser] = useState({
    name: "Aswathi",
    age: 22
    }); 

Functional State Update :
    When the new state depends on the previous state, use the functional updater.

    setCount(prevCount => prevCount + 1);

    Here:

    prevCount → previous state value

    Example:

    const [count, setCount] = useState(0);

    setCount(prevCount => prevCount + 1);

    If count is 0:

    previous value = 0
    0 + 1 = 1

Why use Functional Updater? :

    Consider:

    setCount(count + 1);
    setCount(count + 1);

    Both updates may be based on the same value from the current render.

    When multiple updates depend on the previous state, prefer:

    setCount(prev => prev + 1);
    setCount(prev => prev + 1);

    This tells React:

    "Take the latest previous state and calculate the next state from it."


Multiple useState   :

    A component can have multiple state variables.

    const [name, setName] = useState("Aswathi");
    const [age, setAge] = useState(22);
    const [isOnline, setIsOnline] = useState(true);

    Each state has its own:

    state value
    +
    setter function


Updating Objects in State   :

    Suppose:

    const [user, setUser] = useState({
    name: "Aswathi",
    age: 22
    });

    To change only age:

    setUser({
    ...user,
    age: 23
    });

    The spread operator keeps the existing properties and changes age.

    ❌ Avoid directly mutating:

    user.age = 23;

Updating Arrays in State    :
    const [skills, setSkills] = useState([
    "JavaScript",
    "React"
    ]);

    To add a skill:

    setSkills([
    ...skills,
    "MongoDB"
    ]);

    Result:

    ["JavaScript", "React", "MongoDB"]

Rules of Hooks  :

    There are important rules when using Hooks.

    Rule 1 — Call Hooks at the top level

    ✅ Correct:

    function App() {
    const [count, setCount] = useState(0);
    }

    ❌ Don't call inside if:

    if (condition) {
    useState(0);
    }

    ❌ Don't call inside loops:

    for (...) {
    useState(0);
    }
    Rule 2 — Hooks should be used in React functions

    Hooks can be used in:

    Functional components
    Custom Hooks


Syntax of useState() :
    const [state, setState] = useState(initialValue);
